# MobilePad
Turn your phone into a keypad!

# Install
1. Install Python from https://www.python.org/
2. Write in cmd on PC `pip install flask pynput`
3. Open `main.py` on PC
4. Open the address shown in the console of the `main.py` file on your phone.

# You can
Use the mobilepad as soundpad/streampad
Use mobilepad for games 
Use mobilepad for work 
Customize it to fit any keys, pages, and titles you need.
